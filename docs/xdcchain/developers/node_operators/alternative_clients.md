# Alternative Clients (Experimental)

!!! warning "Experimental. Not for masternodes"
    The supported software for XDC masternodes, standby nodes and full nodes is XDPoSChain (`xinfinorg/xdposchain`), installed by following [Masternode Setup](./masternode.md). The clients on this page are third-party and experimental. Do not use them for mainnet masternode or standby duty.

Running more than one client implementation lets operators test against a second codebase and helps the network's client diversity. This page lists independent implementations that are being tested on XDC test networks.

## xOne (xOneRS)

- **What it is:** a Rust execution client for XDC and Ethereum, maintained by XDCIndia.
- **Status:** experimental. For testnet use only. It does not produce blocks on XDC mainnet and is not a supported replacement for XDPoSChain.
- **Image:** `docker.io/xonesh/xone`
- **Site and docs:** [xone.sh](https://xone.sh/)
- **License:** BUSL-1.1. The source repository is not public yet, pending a security audit.

Figures published on the xOne site are the maintainers' own measurements unless they say otherwise. This listing is not an audit or an endorsement.
